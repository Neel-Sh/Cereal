# Security

Please report security vulnerabilities privately.

The preferred path is a [GitHub Security Advisory](https://github.com/Neel-Sh/Cereal/security/advisories/new) on this repository. You can also email [neelksharma13@gmail.com](mailto:neelksharma13@gmail.com).

Include how to reproduce the issue and what you think the impact is. Please give us a chance to respond before discussing it in public.
